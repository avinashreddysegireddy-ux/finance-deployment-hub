# Finance Deployment Hub

A simple dashboard to track finance-system releases from approval to production.

## Run
Open `index.html` in any browser. No installation or server needed.

## Files
- index.html - page structure
- style.css  - styling (light/dark, responsive)
- app.js     - logic (add, approve, deploy, roll back, filter, localStorage)

## Status flow
Pending approval -> Approved -> Deployed -> Rolled back (can be resubmitted)
